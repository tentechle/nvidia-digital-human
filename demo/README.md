# Digital human demo

Talk to a **photoreal digital human** that runs on your own NVIDIA GPU, and watch each stage of NVIDIA's Tokkio pipeline (the blueprint this repository copies) run as it answers.

```
demo/
├── web/      the explorer page (static, no build step)
├── server/   setup for the LiveTalking avatar server + patch
├── tests/    unit tests for the live-avatar protocol logic
└── docs/     design notes
```

## What you get

- **Avatar:** real video of a person, with the mouth generated by wav2lip on your GPU. The page connects to the avatar server as soon as it loads.
- **Voice:** server TTS (Edge TTS by default), streamed with the video over WebRTC.
- **Answers:** scripted, or **Server LLM**, where NVIDIA's API at build.nvidia.com answers.
- **Pipeline log:** real timings for first audio, each sentence and the end of the turn.

If the avatar server isn't running, the page says how to start it, and in the meantime reads answers aloud with your browser's voice, without video.

## Run the page

```bash
cd demo && npm run serve        # http://127.0.0.1:8765
```

ES modules need HTTP, so opening `index.html` as a file won't work.

## Run the live avatar server (Linux + NVIDIA GPU)

Tested on an RTX 4060 Laptop GPU (8 GB): wav2lip inference at about 60 FPS and a steady 25 FPS stream, using about 2.3 GB of GPU memory.

```bash
cd demo/server
./setup.sh            # LiveTalking (pinned) + patch, PyTorch CUDA 12.8, model + sample avatar (~4 GB)
./set-nvidia-key.sh   # optional: your build.nvidia.com key, for Server LLM answers
./start.sh            # http://127.0.0.1:8010
```

Then open (or reload) the page: it connects by itself. Pick **Server LLM** to have NVIDIA's model answer.

### What the patch changes in LiveTalking

`server/livetalking-nvidia.patch`, applied to LiveTalking at the commit in `server/LIVETALKING_COMMIT`:

- **NVIDIA LLM provider:** adds `--llm_provider nvidia` (`integrate.api.nvidia.com`, default model `nvidia/llama-3.1-nemotron-70b-instruct`, reads `NVIDIA_API_KEY`), with an English spoken-style system prompt. It also logs a clear error instead of crashing when the key is missing.
- **Cross-origin `/sse` fix:** the event stream set `Access-Control-Allow-Origin` itself, and the `aiohttp_cors` middleware the server also installs asserts that header is absent. Every request from a page on another origin therefore failed with an `AssertionError`. The middleware now adds the header alone.
- **Localhost by default:** the server listened on `0.0.0.0`, which exposed its admin console and avatar upload to the local network. It now binds to `127.0.0.1` unless `LT_HOST` is set.

## How the live connection works

`web/js/live/` holds three modules:

- **`livetalking-client.js`** handles the transport:
  - WebRTC offer/answer through `/offer`, with receive-only audio and video
  - commands through `/human` (echo and chat), `/interrupt_talk` and `/is_speaking`
  - speech events through `/sse`
  - **if `/sse` fails** (for example on an unpatched server), it falls back to polling `/is_speaking` and synthesizes the same start/end events, so turns still complete
- **`turn-tracker.js`** decides when a spoken turn has really ended:
  - the server sends `start`/`end` events per audio chunk as the audio actually plays
  - an LLM reply arrives as many chunks, with gaps while the next one is synthesized
  - a short chunk can send `start` with no `end`
  - so a turn ends only after a quiet period **and** once `/is_speaking` confirms it, with timeouts so it never hangs
- **`speakers.js`** gives the runner one interface, `say` / `chat` / `stop` with timing hooks, for both the browser voice and the live server.

The page also notices when the server goes away. A WebRTC connection that stays `disconnected` for 4 seconds is treated as dropped, and the page shows how to restart the server.

## Tests

```bash
cd demo && npm test
```

17 tests with Node's built-in runner, no dependencies. They cover the turn tracker (fake timers), the client's signalling and command protocol (fake WebRTC, fetch and EventSource), and the `/sse` to polling fallback.
